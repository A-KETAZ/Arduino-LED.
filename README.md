# Arduino LED Control :
A simple Arduino Uno project to control an LED using a digital pins.

About:
In this project, an LED is connected to digital pin 12.
The LED turns on for 500 ms and then turns off for 500 ms continuously.
When the Arduino starts, the LED stays on for 3 seconds before the blinking starts.

Components:
* Arduino Uno
* LED
* Resistor 220 Ω (Red-Red-Brown-Gold)
* Breadboard
* Jumper wires

Tools :
* Arduino IDE
* C/C++
